# Нур — приложение для изучения Ислама

Мультиплатформенное приложение (iOS + Android + Web) на React Native + Expo для поэтапного изучения основ Ислама, чтения Корана, запоминания хадисов и арабского языка.

## Что внутри (полная версия)

### Контент
- **Основы Ислама** — 4 модуля, 25 уроков с тестами (Введение, Коран, Хадисы, Практика мусульманина)
- **Коран** — полный список 114 сур через Quran API; локальный fallback из 8 коротких сур работает офлайн
- **Хадисы** — выборка из «40 хадисов» ан-Навави и сахихов с пояснениями
- **Арабские слова** — 79+ слов по 6 категориям с корнями, частотой в Коране, примерами

### Интерактив
- **Аудио чтение** каждого аята — декламация Mishary Alafasy через CDN everyayah.com
- **Времена 5 намазов** — локальный расчёт по координатам через библиотеку `adhan`. 12 методов (Muslim World League, Egyptian, Karachi, Umm al-Qura и т.д.), оба мазхаба для Аср
- **Push-уведомления** — напоминания о намазах и ежедневный аят дня в 08:00
- **AI-помощник** — реальный Claude API при наличии ключа; иначе работает на заготовленных ответах
- **5 типов тестов** — выбор ответа, соединение пар, аудио-распознавание, последовательность, заполнение пропусков
- **Карточки слов** с интервальным повторением (SRS: 1→3→7→30 дней)

### Геймификация и UX
- 5 уровней: Новичок → Студент → Исследователь → Хафиз слов → Знаток Корана
- XP, серия дней подряд, 7 достижений
- 4-шаговый онбординг (цель, уровень, дневная норма)
- Локальное сохранение прогресса через AsyncStorage (без сервера)
- Кэш Quran API на 7 дней — оффлайн-режим после первой загрузки


### Новое (июнь 2026)
- **«Путь арабского»** — направляемая дорожка с нуля до чтения Корана: буквы → огласовки → тренажёр слогов → топ-50 слов → грамматика A1 → короткие суры. Линейная разблокировка, мини-тесты, связка с SRS
- **Разбор слова по буквам** — тап по любому слову аята в Коране: каждая буква с названием, формой и звуком + перевод из словаря
- **Виджет «следующий намаз»** на главной: обратный отсчёт, город, дата хиджры
- **Азкары «После намаза»** + воспроизведение сур чтением Корана (не TTS), отдельные фрагменты
- **Режим Рамадана** — сухур/ифтар, трекеры поста и таравиха
- **Глобальный поиск** по всему контенту, **резервная копия прогресса** (экспорт/импорт)
- **Фоновое аудио** (экран можно блокировать), хаптика, анимации, тёмная тема
- AI-помощник: OpenRouter Free Models Router (бесплатно) или DeepSeek API

## Внешние API (бесплатные, без ключей)

- **AlQuran Cloud** (`api.alquran.cloud`) — суры, аяты, переводы. Используется русский перевод Кулиева.
- **everyayah.com** — mp3 аятов в декламации Mishary Alafasy и др.
- **Anthropic API** — только если хотите подключить настоящий AI; ключ опциональный.

## Запуск

```bash
cd NurApp
npm install   # автоматически применит фиксы из patches/ через patch-package
npm start
```

После запуска:
- **iOS:** `i` (Xcode + iOS Simulator) или QR-код в [Expo Go](https://apps.apple.com/app/expo-go/id982107779) на iPhone
- **Android:** `a` (Android Studio + эмулятор) или QR-код в Expo Go
- **Web:** `w`

> **Рекомендованный Node:** 22.x LTS. На Node 26 ломается `@expo/cli` (без нашего патча).

## Патчи зависимостей (patches/)

В папке `patches/` лежат фиксы для двух библиотек. `postinstall: patch-package` в `package.json` применяет их автоматически после каждого `npm install`. Лезть в `node_modules` руками не нужно.

- **`react-native-gesture-handler+2.28.0.patch`** — Metro в SDK 54 резолвит библиотеку через поле `"react-native": "src/index.ts"` (то есть берёт TypeScript-исходники, а не скомпилированный `lib/`). В `src/handlers/gestures/GestureDetector.tsx` библиотека импортирует `baseGestureHandlerWithMonitorProps`, `filterConfig`, `findNodeHandle`, `scheduleFlushOperations` из `gestureHandlerCommon`, но первого имени там нет вообще (есть только `baseGestureHandlerWithDetectorProps`), а остальные три живут в `handlers/utils.ts`. На bootstrap выполняется `[...baseGestureHandlerWithMonitorProps]` — spread из `undefined` в Hermes даёт `TypeError: Cannot convert undefined value to object`, и приложение не стартует. Патч заменяет первый импорт на alias правильного экспорта и перетаскивает три функции в отдельный импорт из `../utils`.
- **`expo+54.0.34.patch`** — в `expo/node_modules/@expo/cli/build/.../waitForMetroToObserveTypeScriptFile.js` `for (const event of eventsQueue)` падает с `TypeError: eventsQueue is not iterable`, когда вотчер пришлёт пустой `change`-эвент (Node 22.22+/Watchman может). Патч превращает три места в `eventsQueue || []`.

### Если поднимаем версии библиотек

После `npm install` нового мажора `react-native-gesture-handler` или `expo` патч может не приложиться (изменился контекст). Алгоритм:

1. Удалить `patches/имя+старая-версия.patch`.
2. Руками внести правку в соответствующий файл в `node_modules`.
3. Запустить `npx patch-package react-native-gesture-handler` (или `npx patch-package expo`). patch-package сравнит текущий файл с оригиналом из npm и сложит новый diff в `patches/`.
4. Закоммитить новый patch-файл.

В нашем случае генерация через `npx patch-package` падает из-за кириллицы в пути проекта (npm не может ставить пакет во временную папку). Если такое повторится — патч можно составить руками, шаблон есть в существующих файлах.

## Конфигурация AI-помощника (опционально)

Без ключа AI работает на заготовленных ответах. Чтобы подключить настоящий Claude:

1. Получите ключ на [console.anthropic.com](https://console.anthropic.com/)
2. Откройте `app.json` и заполните `extra.claudeApiKey`:
   ```json
   "extra": {
     "claudeApiKey": "sk-ant-api03-..."
   }
   ```
3. Перезапустите приложение

⚠️ В production-приложении НЕ кладите ключ в клиент — поднимите proxy (Cloudflare Worker / Lambda), который добавляет ключ на стороне сервера. См. комментарии в `src/services/aiService.js`.

## Достоверность контента

Тексты Корана и хадисов сверены с авторитетными источниками:

- **Коран:** короткие суры (Аль-Фатиха, Аль-Ихлас, Аль-Фаляк, Ан-Нас, Аль-Аср и др.) в Усманском своде. При запуске на устройстве полный текст любой суры подгружается через [AlQuran Cloud API](https://alquran.cloud/api), который использует тот же стандартный мусхаф.
- **Хадисы:** «40 хадисов» имама ан-Навави и подборки из Сахих аль-Бухари и Сахих Муслим. Первый хадис о намерениях сверен с [Sunnah.com](https://sunnah.com/bukhari:1) посимвольно — арабский текст совпадает.
- **Русский перевод Корана:** в онлайн-режиме используется перевод Эльмира Кулиева (`ru.kuliev`) — один из самых распространённых академических переводов.
- **Времена намазов:** библиотека `adhan` реализует классические астрономические алгоритмы (используется ICCI, Halal Foods, Athan Pro и др.).

Для серьёзного религиозного применения рекомендуется сверять конкретные хадисы и тафсиры с печатными изданиями авторитетных учёных.

## Как расширять контент

- **Уроки:** `src/data/modules.js` → добавьте элементы в `lessons`. Связанный тест — в `src/data/quizzes.js`.
- **Хадисы:** `src/data/hadiths.js` → массив `hadiths`.
- **Слова:** `src/data/words.js` → массив `words`. Категория задаётся `category`.
- **Тесты:** `src/data/quizzes.js` — 5 поддерживаемых типов: `choice`, `match`, `audio`, `sequence`, `fill`.
- **Суры/Коран:** локальный fallback в `src/data/quran.js`; полный набор подтянется автоматически через `src/services/quranService.js`.

## Тёмная тема

Поддерживается. В **Профиль → Оформление** три режима:

- ☀️ Светлая
- 🌙 Тёмная
- ⚙️ Системная (следует за настройкой iOS / Android)

Палитры заданы в `src/constants/theme.js` (`lightColors` и `darkColors`).
Тема пробрасывается через `ThemeProvider` (`src/store/themeStore.js`) и сохраняется в AsyncStorage.
