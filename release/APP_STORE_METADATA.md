## App Privacy — “Data collected”

В опроснике App Privacy отвечать:

- **Do you collect data?** → No, we do not collect data from this app.
  - На этом всё, дальше вопросов нет.

Если Apple попросит уточнить, что делает Location, Notifications, Microphone:
- **Location:** used only on-device for prayer time calculation, not transmitted.
- **Notifications:** local only, scheduled on-device.
- **Microphone:** declared for `expo-audio` dependency; not actually used.

## App Review — заметки для рецензента (Notes)

```
The app does not require a login. All features are accessible immediately after install.

The AI Assistant (Profile → AI Assistant) requires the user to paste their OWN API key from OpenRouter or DeepSeek. Without a key, that screen shows instructions on how to obtain one — this is by design; we do not bundle any key.

Location is used only when the user opens “Prayer Times”. Coordinates never leave the device.

Notifications are scheduled locally to remind about prayers and the daily ayah.

Hadith source links open in the system browser and lead to sunnah.com or isnad.link — publicly available Islamic scholarly sources.
```

## Скриншоты — что снять в Simulator

Минимум 3, максимум 10 для каждого размера. Рекомендация — 5 самых ярких:

1. **Главная** с приветствием, аятом дня, суннами
2. **Коран** — открытая сура с арабским, транскрипцией, переводом, кнопкой play
3. **40 хадисов** — список
4. **Времена намаза** + кибла
5. **Адхкары** — с табами AR / TR / RU

Требуемые размеры iOS (2026 год):
- **6.9" iPhone 16 Pro Max:** 1320×2868
- **6.5" iPhone 11 Pro Max / XS Max:** 1242×2688 или 1284×2778
- **12.9" iPad Pro (6th gen):** 2048×2732 — обязательно, т.к. `supportsTablet: true`

Быстрый способ:
```bash
xcrun simctl list devices | grep 'iPhone 16 Pro Max'
# запусти на нужном симуляторе, погоняй экраны, ⌘S сохраняет скриншот на десктоп
```
